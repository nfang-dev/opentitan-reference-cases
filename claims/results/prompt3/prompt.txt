You read one sentence from the hand-written documentation of a hardware block and list the register facts that the sentence states.

Record a claim only for these four properties, and only when the sentence itself states it:
- reset_value: the value a register or field has after reset. The sentence must say so with words such as "reset", "default", "initial" or "power-on", for example "resets to 0", "is 1 by default", "is disabled after reset". Value: a number, decimal or 0x hexadecimal. For a one-bit field, enabled or set is 1, disabled or cleared is 0.
- software_access: the access type of a register or field. The sentence must name the type ("read-only", "write-only", "read/write") or say what a software write does to the register's own value ("writing 1 clears it", "write 0 to acknowledge it", "writes are ignored"). Value: one of read-write, read-only, write-only, write-1-to-clear, write-1-to-set, write-0-to-clear, read-to-clear.
- width_bits: the number of bits of the register or field itself, for example "the 12-bit prescaler field". Value: a number.
- locked_by: a register that, once cleared, stops software from writing this register, for example "writes to X are disabled by clearing Y". Value: the name of the locking register.

Rules:
- Use only what the sentence states. Do not use your own knowledge of this or similar hardware, and do not guess a property from what a register is used for.
- A value that software writes as a step of a procedure ("write 0x1 to X to enable it") is not a reset value.
- Saying that software reads or writes a register does not state its access type. Setting or clearing a field as a step of a procedure is how any read-write field is written: it states an access type only if the sentence says that the write has a special effect on the field, such as clearing it when 1 is written.
- A lock register does not lock itself: locked_by is a property of the registers it protects, and only of those the sentence names.
- The width of data, of a part of a write, or of a value range is not the width of a field.
- A sentence that only says what software should do, or how the hardware behaves, has no claims. Most sentences have none.
- register: a register name from the list given with the sentence. field: a field name from that list, or "" when the claim is about the whole register.
- quote: the exact words of the sentence that state the claim, including the words that name the property or its effect ("reset", "default", "read-only", "clear", "acknowledge", "12-bit", "lock"). A program checks every claim and rejects a quote without such words.
- If the sentence states none of the four properties, answer {"claims": []}.
